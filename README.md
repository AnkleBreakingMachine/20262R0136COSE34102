# Python Programming Examples

## Overview

This repository contains 10 independent Python programs demonstrating fundamental programming concepts, algorithms, and data structures.

The programs were created to practice Git version control and maintain meaningful commit histories.

## Implementations

| File | Description |
|---|---|
| 01_hello.py | Demonstrates basic output and variables. |
| 02_calculator.py | Implements basic arithmetic operations with division-by-zero handling. |
| 03_prime.py | Determines whether a number is prime. |
| 04_factorial.py | Calculates factorials using recursion. |
| 05_fibonacci.py | Generates Fibonacci numbers iteratively. |
| 06_palindrome.py | Checks whether a string is a palindrome. |
| 07_sort.py | Implements the Bubble Sort algorithm. |
| 08_binary_search.py | Searches a sorted array using Binary Search. |
| 09_word_count.py | Counts word frequencies in a sentence. |
| 10_stack.py | Implements a stack with push, pop, and peek operations. |

## Development Environment

- OS: Ubuntu (WSL2)
- Editor: Visual Studio Code
- Language: Python 3
- Version Control: Git and GitHub

## How to Run

Run any program using Python 3:

```bash
python3 01_hello.py
```

Replace the filename with the program you want to execute.
